# 따찌 · Ddatzzi

외부 마우스를 연결하면 휠의 위아래 스크롤 방향을 바꿔주는 macOS 메뉴 막대 앱입니다.

[설치 파일 다운로드](https://github.com/mindsurf0176/ddatzzi/releases/tag/v1.0.0)

## 설치

1. 릴리스에서 `Ddatzzi-1.0.0-universal.dmg`를 다운로드합니다.
2. DMG를 열고 **Ddatzzi**를 **Applications**로 드래그합니다.
3. 응용 프로그램에서 Ddatzzi를 실행합니다. Dock 대신 메뉴 막대에 마우스 아이콘이 나타납니다.
4. 앱 안내에 따라 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Ddatzzi를 허용합니다.

ZIP을 내려받았다면 압축을 풀고 Ddatzzi.app을 응용 프로그램 폴더로 옮겨 실행하세요.

## 사용

- 외부 마우스의 연결·해제를 약 2초 안에 반영합니다.
- 일반 휠의 위아래 방향을 반전합니다. 트랙패드의 연속 스크롤과 가로 스크롤은 유지합니다.
- 메뉴의 **마우스 휠 방향 반전**을 끄면 기존 방향으로 돌아옵니다.
- **로그인할 때 실행**을 켜면 다음 로그인부터 자동 실행됩니다.
- macOS의 ‘자연스러운 스크롤’ 설정은 바꾸지 않습니다.

## 요구 사항과 지원 범위

- macOS 13 이상. Apple Silicon·Intel용 통합 앱입니다.
- 일반적인 휠 마우스의 불연속 스크롤을 대상으로 합니다. Magic Mouse나 일부 부드러운 스크롤 드라이버가 보내는 연속 스크롤은 반전되지 않을 수 있습니다.
- 다른 스크롤 반전 앱과 함께 실행하면 결과가 달라질 수 있습니다.
- 무선 수신기는 마우스 전원을 꺼도 연결된 장치로 남을 수 있습니다.

## 권한을 켰는데 동작하지 않을 때

이전 테스트 버전을 허용했다면 손쉬운 사용 목록의 Ddatzzi를 제거한 뒤, 현재 응용 프로그램 폴더의 Ddatzzi를 다시 추가하고 허용하세요. 다른 경로에 복사본이 있으면 종료하고 사용할 앱 하나만 실행하세요.

## 개인정보와 문의

앱은 계정, 네트워크 요청, 분석 수집 없이 Mac 안에서 동작합니다. 스크롤을 바꾸는 데 필요한 손쉬운 사용 권한을 사용합니다.

문제는 [Issues](https://github.com/mindsurf0176/ddatzzi/issues)에 macOS 버전과 마우스 모델, 메뉴에 표시되는 상태를 함께 남겨주세요.

이 저장소는 설치 파일과 사용 안내만 공개합니다. 앱 소스코드는 비공개입니다. GitHub가 자동으로 표시하는 **Source code** 압축 파일은 이 안내 저장소의 내용이며, 앱 설치 파일은 DMG 또는 ZIP입니다.
